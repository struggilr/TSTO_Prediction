# V8候选：局部几何度量条件化

## 先前诊断及其约束

V7中间检查点的五个验证窗口显示，稠密网格上相对Cartesian的误差比为p 0.948、rho 0.998、T 1.157、u 0.908、v 1.230。固定监督格点与其他格点的比值没有明显恶化差异，暂不支持把主要问题归于稀疏格点过拟合。

单个训练窗口的激波压力/密度梯度与温度、Y速度目标余弦均为正，不支持该窗口存在一阶方向冲突；不能推导全训练分布无冲突。冻结V3权重后，把跨图上下文强度从0.25降到0.125或0，使验证误差变大，因此不采用直接删除上下文的办法。

## 数学动机

令物理坐标映射为(x,y)=Phi(xi,eta)，D Phi的两列为e_xi=(x_xi,y_xi)、e_eta=(x_eta,y_eta)，J=x_xi*y_eta-x_eta*y_xi。在局部J非零处：

    d/dx = (y_eta*d/dxi - y_xi*d/deta)/J
    d/dy = (-x_eta*d/dxi + x_xi*d/deta)/J

因此逻辑坐标上的相同卷积尺度，不一定对应相同物理尺度。现有网络能从坐标间接学习这一关系，但没有显式提供局部间距、方向及Jacobian。V8将这些可由过去坐标计算的量直接提供给特征编码器；这是待验证的归纳偏置，不宣称可保证提高预测精度。

8个输入特征为：e_xi单位方向2维、e_eta单位方向2维、两个长度的对数、夹角余弦、绝对Jacobian的对数。长度和Jacobian相对于共同物理网格尺度无量纲化。数值退化处作明确截断以保证有限值；不据此宣称网格全局可逆。

几何特征仅由历史输入坐标获得，未读取未来真实轨迹或流场。一个两层1x1卷积编码器将特征映射到24维并加到原细尺度特征上，共增加816参数。末层零初始化，初始预测与原V3逐位一致。初始化新分支时保留原CPU随机数流，以免仅因新增参数改变已有训练窗口洗牌顺序。

## 受控训练

V8从与V7相同的V3验证选择检查点初始化，使用同样的60轮、学习率、物理回映射监督、原生损失权重及验证准则。模型总参数由340349变为341165。它是V7与几何特征分支的对照，不是与原Cartesian完全相同预算的网格表示消融。

该候选已通过仿射几何/Jacobian检查、平移不变性、新分支梯度检查、真实窗口零初始化预测一致性检查。以上仅证明实现性质，不能当作性能证据。

run_metric_v8_local.py仅在V7完整评估未满足五通道全域及高梯度压力/密度条件时，才会启动V8冒烟测试及正式训练。V7运行期间不修改其代码、缓存和检查点。

测试后保留所有结果。继续优化的目标不变，但不能通过换指标、挑帧、在预测时读取真实未来场或弱化Cartesian来达标。
