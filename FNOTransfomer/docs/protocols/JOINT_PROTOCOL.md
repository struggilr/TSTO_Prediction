# 历史输入的流场—轨迹联合预测（正在验证）

替换旧版“已知未来几何”实验。旧server.zip仍为旧实验，请勿用来完成新目标。

共同来源E:/fenli五条Ma5–7轨迹，全部500帧。基础数据沿用cgns2npz最近邻插值、280×440固定区域[-10,100]×[-20,50]、五物理变量和时序目标窗口规则。修正旧脚本以zone6/7作壁面的错误，按smj/xmj命名壁面识别；不修改原V2.0文件。训练/验证/测试按每条序列70%/10%/剩余帧，严格按真实文件名时间排序，归一化仅训练帧。

A：基础规则网格直接输入。B：相同基础网格双线性采样到TAOCA四图。两路每帧123200点（A 280×440；B 4×70×440）；模型结构与参数相同，但形状导致FNO计算量不同，需记录耗时。B改变图数、采样位置是TAOCA表示本身，不能宣称所有底层计算完全相同。

前20帧→未来10帧，可通过--history/--horizon调整（必须保证验证段容纳目标）。模型输入仅历史物理场、历史有效mask/坐标、历史双体位姿、历史时间步和Mach；目标未来物理场/位姿只进入损失和评价。不使用未来真实mask生成预测。已知物体形状来自第一帧，未来形状位置来自预测位姿。

代理：历史GRU+历史场统计学习加速度残差，叠加从历史最后两帧估计的匀速基线，预测双体x/y/姿态角。该方法是学习的运动代理，不是六自由度力学求解；无质量/惯量/外载荷闭环时不声称求解6DOF。位姿标签是命名壁面节点几何中心和连续主轴方向，不是质量中心。历史真实位姿视为观测。

预测图：近体图随对应预测刚体位姿运动；outer固定；gap按距离混合两体位移。这是新增的预测图输运近似，尚未证明非翻折和全局覆盖。必须审计单元方向、覆盖、固体区、轨迹误差并报告失败，不能混用旧真实未来图的逆映射。

train_joint.py是新入口；旧train_compare.py是条件预测入口。scripts/prepare_joint.py重建基础数据；scripts/check_joint_contract.py验证前向接口无未来真值，目标修改不改变输出。当前训练损失在预测图上从真值基础网格采样，未来真值只用于监督；几何采样坐标在损失中detach，防止通过移动采样位置投机降损失。预测固体mask必须单独检查。

当前评价把预测图重构到基础网格，报告轨迹米/弧度误差、归一化物理场误差、覆盖和翻折。候选三角形搜索可能遗漏覆盖；正式方法比较仍需两路共同物理支持、全域缺测惩罚和非重叠时序评价的完善。当前不能宣称论文级闭环已完成。
