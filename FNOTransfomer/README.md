# FNOTransfomer — V_best（TAOCA V9）

本目录只保留官方统一比较中最佳的 TAOCA V9 代码与依赖模块。历史版本代码不在 GitHub；完整说明和误差表见仓库根目录 README 附录，以及本机整理目录 other_version/README.md。

## 结果概览

同一共同合法支持域九路线比较中，V9 五通道平均 train-std NRMSE 为 **0.245286**，是已完成 TAOCA 路线最低。相对主 Cartesian，压力、密度误差分别高 1.64%、2.22%；温度、速度X、速度Y分别降低约 11.6%、33.3%、4.0%。近壁五通道均改善，高梯度区压力/密度分别退化约 6.0%/27.5%。因此它是综合平均最优，不代表每个通道均优于Cartesian。

比较包含单随机种子、540个重叠预测实例、54个窗口和99个唯一目标帧；测试集曾被多轮诊断使用。结果属于探索性比较，不是独立泛化证明。

## 目录结构

- V_best/：V9 训练、图册/物理映射、评价代码和协议。
- 数据集、检查点、缓存和图件不在仓库中。

## 复现说明

训练需要原始TSTO数据及派生HDF5、共享轨迹模型、V8初始化权重、Cartesian对照检查点、V7物理算子缓存和运行元数据。数据和权重不在仓库中，干净clone不能直接复现已报告训练结果。先按本地实验协议准备这些外部输入，再从 V_best/ 入口运行。

```bash
python -m pip install -r V_best/requirements.txt
```
