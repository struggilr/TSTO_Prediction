# TAOCA采样预算重新分配实验 V3

本轮只重训练TAOCA，保留physics_v2的Cartesian最佳权重和测试缓存。该实验回应“保住近壁收益、改善激波表示”的问题，不预设TAOCA必然胜出。

## 已完成的验证集诊断

使用原V2 TAOCA最佳权重，对全部5个验证窗口、每窗10步共50个预测实例，分别检查四图和融合结果。没有用测试集选择融合或分配方案，也没有用真实答案逐点挑选图。

预先指定的融合候选为质量加权、等权、背景权重乘4、背景权重乘16、取最大质量图。以同域五通道平均NRMSE为选择指标，并要求平均近壁NRMSE不比原质量融合差超过3%。结果仍是原质量融合最好，因此不通过人为改融合权重制造改善。

四张图独立误差使用各自覆盖区，不能把覆盖不同区域的图直接按一个NRMSE数值排名。图件和数据见`outputs/atlas_v3/diagnostic_figures/`、`fusion_diagnosis.json`、`validation_native/`。

## 新分配及其依据

| 图 | V2尺寸 | V3尺寸 |

| 物体1近体O图 | 70×440 | 35×440 |
| 物体2近体O图 | 70×440 | 35×440 |
| 背景环形图 | 70×440 | 140×440 |
| gap图 | 70×440 | 70×440 |
| 采样点总数 | 123200 | 123200 |

还预先比较了49/49/112/70和42/42/126/70两组中间分配。三个候选都通过门槛，35/35/140/70的表示指标最好。

选择门槛在候选评价前记录在selection_contract.json：平均五通道真值往返NRMSE至少降低5%；高压力梯度候选区压力/密度的平均往返NRMSE至少降低10%；平均近壁往返NRMSE增加不超过10%；真值有效供体覆盖下降不超过0.2个百分点；几何合法覆盖至少99.5%；没有非正三角形。

在全部50个验证实例、所有分配的共同真值有效物理点上，新方案的五通道平均往返NRMSE降低约23.88%，高压力梯度区压力/密度平均往返NRMSE降低约22.52%，平均近壁往返NRMSE降低约20.56%。几何合法流体像素覆盖从99.8925%变为99.9156%；真值采样供体进一步要求目标mask完整有效，其覆盖约98.95%，不能与上述几何覆盖混为一谈。

这些是“真值→图册→物理网格”的表示诊断，不是神经网络预测提升，不是误差下界，也不能与预测RMSE简单相减。分配、几何尺度变化与几何质量融合权重之间存在联动，不能把收益全部归因于某一个单独因素。

![同域真值往返误差比较](outputs/atlas_v3/diagnostic_figures/validation_allocation_roundtrip.png)

新方案是**静态固定预算分配**，保留历史逻辑相位；没有使用未来真实激波位置布点，也没有宣称已经完成动态激波自适应网格。未来几何仍由共享的历史轨迹代理推进。

## 代码与公平性

- 新数据接口：`taoca/allocated_data_v3.py`，保持同一源数据、归一化、时序划分、20→10窗口。
- 新图册接口：`taoca/allocation_v3.py`，只改变四图径向尺寸，周向均440，外边界与图角色不变。
- 网络接口：`taoca/allocated_model_v3.py`，继承V2全部参数和模块，支持不同图高；跨图特征为适应不同逻辑尺寸进行插值。Cartesian及等高输入直接使用原V2 forward。
- 为复用同一物理损失，张量有掩膜补齐；编码器会逐图裁回真实尺寸。测试确认补齐行不进入编码器，改变补齐数据也不改变预测。
- 总参数仍340349；seed42、100轮、AdamW、学习率3e-4、相同余弦衰减、相同物理和区域损失。初始化重新开始，不偷偷复用已经看过测试集的TAOCA权重进行本轮优化。
- 不同图尺寸的算子取整、循环及跨图插值会影响计算量；相同采样点和参数不意味着相同运行耗时，最终必须报告实际成本。
- 源码核查确认共享模型、损失、轨迹和原数据清单与冻结Cartesian运行一致。相同权重下Cartesian分支逐位一致，故无需重新训练Cartesian。

## 已完成的实现检查

选择后的35/35/140/70配置已经通过参数数量、实际编码点数、补齐隔离、Cartesian逐位一致和非零频率梯度检查。3次真实训练窗口优化有限且损失下降；还通过1个完整测试窗口10步的smoke推理、合法回映射和缓存接口。smoke只验证代码，不用于配置选择或性能主张。

正式入口为`python run_atlas_v3_local.py`，会检查表示门槛与技术门槛，随后只训练TAOCA 100轮，自动评价全部54×10测试实例，最后与固定Cartesian和旧TAOCA在三者共同合法物理域比较。

状态：`outputs/atlas_v3/pipeline_status.json`及`taoca/status.json`；日志：`taoca_train.log`；配置：`allocation_selection.json`；权重与预测：`taoca/`；最终结果：`comparison.json`。不要把physics_v2的完成状态误认为V3已完成。

本轮仍是单随机种子、相同5条Mach序列后段的条件滑窗研究。该测试集已多次用于研究诊断，不应包装为从未接触过的独立最终检验。后续投稿还需独立轨迹或工况验证。
